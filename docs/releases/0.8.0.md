# Kaeru 0.8.0

The memory API now exposes 35 named operations shared by MCP, HTTP and Rig.
Requests use one canonical catalogue; results report committed state, currentness,
coverage, continuations and partial remote effects. Legacy verb names and HTTP
aliases are removed. See the API reference for migration and the current contract.
Existing vaults migrate on open while retaining recorded history.

The release improves scoped discovery, semantic closure, delivery read traces
and atomic mutation/replay behavior. Keyed node and temporal reads use prefix
joins. Cloud imports restore only the imported node's incident edges and retain
local retractions and weights. Full cloud reads can return a scoped record
without importing it; request cancellation and partial imports remain explicit.

Guided tool-use validation covered 27 scenarios with three repetitions on
GPT-6.1-Sol low: 80 of 81 attempts passed, all 81 executed successfully. The
remaining attempt omitted archival promotion; it is retained as an agent
behavior failure. This validates the evaluated integration scope, not perfect
model reliability or exhaustive coverage of every operation.
